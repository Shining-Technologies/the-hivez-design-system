# The Hivez design system

Documentation site for the Hivez app design system: foundations (colour, type, shape, icons, motion, layers), components (buttons, fields, pickers, controls, toolbar controls, overlays, tiles and cards) and page patterns, rendered from the real app components in all three themes, light and dark.

Live: https://shining-technologies.github.io/the-hivez-design-system/

This repo only holds the built site. It is built from `client/design-site` in the app repo (`npm run build:design-site`) and published on request.
